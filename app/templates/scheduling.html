Theoretical OS Simulation vs Actual Docker Process Execution

This simulator evaluates classic OS CPU scheduling algorithms using jobs' estimated burst times and priorities to compute theoretical ready queues, waiting times, and turnaround times. This is strictly distinct from real Docker execution: actual containers run under Linux kernel Completely Fair Scheduler (CFS) with cgroups resource boundaries managed by our background worker service.

Resource Safeguards: Round Robin time slicing addresses starvation but does not prevent deadlock. Deadlock mitigation in our cloud engine relies on atomic two-phase reservation with row locking (SELECT ... FOR UPDATE) and pre-execution capacity validation.
