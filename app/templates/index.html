Engineered for Production Cloud Principles

Explore the core capabilities of the resource scheduling and execution pipeline.

Dynamic Resource Estimation

Database-driven rules compute exact CPU cores, memory MB, and execution runtime based on real workload input dimensions and scaling multipliers.

Safe Node Allocation

Best-fit algorithm with transactional row-level database locking (FOR UPDATE) prevents over-allocation and race conditions under concurrent load.

Real Docker Integration

Uses Python Docker SDK to run isolated non-privileged containers with precise CPU shares, memory caps, timeout supervision, and log streaming.

OS Scheduling Simulator

Simulates Round Robin (configurable quantum), FCFS, SJF, and Priority algorithms side-by-side with Gantt charts, waiting and turnaround time metrics.

Supported Workloads

Four Pre-built Docker Workload Containers

Each workload executes standalone logic inside dedicated containers with clean parameter parsing, resource bounding, and JSON telemetry output.

  • Image Processing: Multi-pass blur, sharpen, grayscale, resize, edge detection using Pillow.
  • Data Analysis: Statistical calculations (mean, median, stdev, quartiles, Pearson correlation).
  • File Processing: Dynamic document synthesis, word and character frequency NLP analysis.
  • Video Conversion: Compute-heavy frame generation with zlib stream compression.
